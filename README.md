# Gestión Integral PH y Jurídica S.A.S. — GitHub Pages

Esta carpeta contiene una versión estática de la página web, lista para publicar con GitHub Pages.

## Publicación rápida

1. En GitHub, crea un repositorio nuevo, por ejemplo `gestion-integral-ph-juridica`.
2. Sube `index.html` a la raíz del repositorio (no dentro de otra carpeta).
3. Abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
6. Espera a que GitHub Pages despliegue el sitio. La URL aparecerá en la misma sección de Pages.

## Notas

- Es un sitio estático HTML/CSS/JavaScript; no necesita WordPress ni servidor PHP.
- El formulario prepara una consulta y la abre en WhatsApp; no guarda ni transmite datos a un servidor propio.
- Los teléfonos, correo y dirección deben verificarse antes de publicar.
- Se puede conectar un dominio propio desde **Settings → Pages → Custom domain**.
